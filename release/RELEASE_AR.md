# دليل الإصدار (من الجوال فقط)

## 1. مفتاح الإصدار (مرة واحدة في عمر التطبيق)
محرر Godot على أندرويد لا يصنع مفتاح إصدار. نصنعه بتطبيق **Termux** (من F-Droid، لأن نسخة Google Play قديمة).

```
pkg update
pkg install openjdk-17
keytool -genkeypair -v -keystore madar-release.keystore -alias madar -keyalg RSA -keysize 2048 -validity 10000
```
- سيطلب كلمة مرور (6 أحرف على الأقل) ثم اسمك وبلدك. البيانات لا تظهر للاعبين.
- انقل الملف إلى مجلد يراه Godot:
```
termux-setup-storage
cp madar-release.keystore ~/storage/shared/Documents/
```

**تحذير مهم:** إذا ضاع هذا الملف أو كلمة مروره فلن تستطيع تحديث التطبيق أبدًا بنفس الاسم. احفظ نسختين: واحدة في Google Drive، وواحدة خارج الجوال. **لا ترسل الملف ولا كلمة المرور لي أو لأي أحد.**

## 2. ربط المفتاح في Godot
مشروع ← تصدير ← Android Release ← Keystore:
- Release: مسار الملف (Documents/madar-release.keystore)
- Release User: `madar`
- Release Password: كلمة المرور

Godot يحفظ كلمة المرور في `.godot/export_credentials.cfg` وليس في `export_presets.cfg`، لذلك مشاركة ملف المشروع لا تكشفها. لا تشارك مجلد `.godot`.

## 3. قبل كل إصدار
1. ارفع الرقم في `project.godot` (config/version) وفي إعداد التصدير (version/code يزيد 1 دائمًا، وversion/name مثل 1.0.0).
2. صدّر **Android Debug**، ثبّته، وافتح أدوات المطور ← **بوابة الإصدار**:
   - شغّل الفحوص التلقائية. يجب أن تكون كلها PASS.
   - أكمل الفحوص اليدوية الـ22.
   - انسخ التقرير وأرسله.
3. إذا قالت البوابة «جاهز للإصدار»: صدّر **Android Release** (تحذف أدوات المطور تلقائيًا).
4. ثبّت نسخة Release فوق نسخة Debug: إذا رفض التثبيت فهذا طبيعي (توقيع مختلف). احذف Debug أولًا، **وصدّر حفظك قبل الحذف**.

## 4. شروط ما زالت مفتوحة
- **الأسئلة:** البوابة تفشل حتى تُراجَع كل الأسئلة يدويًا (574 حاليًا). المشكوك فيها لا تظهر في اللعب لكنها تحتاج قرارًا.
- **القياسات:** لم يصلني أي تقرير أداء أو اختبار من جهاز حقيقي حتى الآن.

## 5. Google Play (لاحقًا)
Play يطلب AAB وليس APK، وهذا يحتاج بناء Gradle غير متاح في محرر الجوال. الخيارات: كمبيوتر، أو خدمة بناء سحابية. سنخطط له بعد أن تثبت نسخة APK مستقرة.
