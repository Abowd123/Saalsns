## المزايا
- واجهة عربية RTL، وألوان وخطوط وأزمنة حركة موحدة من `core/tokens.gd` و`motion/motion.gd`.
- نجوم وXP وعملات وإنجازات ومتجر تجميلي وتحدٍّ يومي بلا إنترنت، مع حماية من الاحتساب المزدوج وتغيير الساعة.
- حفظ آمن (نسختان احتياطيتان وchecksum)، وتصدير التقدم واستيراده.
- إعدادات الجودة (تلقائي، عالية، متوازنة، منخفضة) و«تقليل الحركة» ووضع عمى الألوان.
- كل مرحلة مُثبتة بسكربت في `tools/` (انظر «التحقق»).

## التشغيل
1. ثبّت Godot **4.7.2** (سطح المكتب أو محرر أندرويد).
2. افتح `project.godot`. المشهد الرئيسي `core/boot.tscn`.

## بناء APK على GitHub
`.github/workflows/android.yml` يبني نسخة Android Debug عند كل رفع وينشرها في Releases باسم `debug-latest`. التفاصيل في `release/CLOUD_BUILD_AR.md`. نسخة Release موقّعة تحتاج مفتاح الإصدار كـ GitHub Secrets (`release/RELEASE_AR.md`).

## التحقق
- **داخل التطبيق** (نسخة debug): الإعدادات ← أدوات المطور ← «اختبارات الأنظمة» و«بوابة الإصدار» (اختبارات الوحدات، واختبار دخان يشغّل كل مراحل كل الألعاب).
- **سكربتات المحتوى** (Python 3، بلا مكتبات خارجية، و`cairosvg` اختياري لرسم صور خمّن الصورة). تعمل تلقائيًا في `.github/workflows/content.yml`:

| السكربت | ما يثبته |
|---|---|
| `tools/maze_gen.py --check` | كل متاهة لها حل (BFS)، وأقصر طريق مخزّن |
| `tools/escape_check.py` | كل غرفة يُهرب منها بأدلتها، وكل رمز يُعاد حسابه من الأدلة |
| `tools/speed_check.py --check` | جولات سرعة البرق وأهداف الصائد (500 و300 بذرة) مع بصمة تطابق Godot |
| `tools/guess_check.py --check` | 152 صورة فريدة صالحة، ولكل مرحلة 10 أسئلة على الأقل |
| `tools/packing_gen.py --check` | كل مرحلة تعبئة لها حل واحد بالضبط (Algorithm X) |
| `tools/pipe_cost_gen.py --check` | أقل تكلفة مثبتة بالبرمجة الديناميكية (Dreyfus-Wagner) |
| `tools/physics_lab_gen.py --check` | كل تركيبة محاكاة، والحل المحفوظ ينجح حتى مع اضطراب بسيط |
| `tools/bridge_gen.py --check` | الطريق وحده ينكسر، والتصميم المحفوظ يحمل سيارة أثقل 20% |
| `tools/gd_lint.py` | فحوص GDScript ثابتة (تقريبية) |

## البنية
```
core/      الأنظمة المشتركة (autoloads): الحفظ، التقدم، الإعدادات، الجودة، الكتالوج...
ui/        مكتبة الواجهة: أزرار، بطاقات، أيقونات SVG، أعلام، مؤثرات
motion/    رموز الحركة وأدوات Tween
meta/      الرئيسية، العوالم، الإنجازات، المتجر، الإعدادات، الملف الشخصي
games/     لعبة في كل مجلد، وكلها ترث MiniGame (games/mini_game.gd)
content/   الكتالوج والمراحل والأسئلة (JSON)
devtools/  الاختبارات وأدوات المطور (لا تدخل نسخة Release)
tools/     مولّدات المراحل ومدققاتها (Python، لا تدخل التطبيق)
release/   الخصوصية، وصف المتجر، قائمة الجودة، خطوات الإصدار
```
إضافة لعبة: مجلد في `games/` ومشهد يرث `MiniGame`، وسطر في `content/catalog.json`.

## قبل النشر في المتجر
- مفتاح توقيع Release (`release/RELEASE_AR.md`).
- استبدال الموسيقى المؤقتة `assets/music/ambient_menu.ogg` (مذكورة في `LICENSES.md`).
- إكمال مراجعة الأسئلة البشرية (بوابة الإصدار تعرض العدد المعلق).
- إضافة بريد التواصل في `release/PRIVACY_POLICY.md`.

**Madar** is a fully Arabic, offline Android game collection (25 games, 4 worlds) built with Godot 4.7.2 / GDScript. No ads, no tracking, no purchases. Every level is machine-verified by the scripts in `tools/` (run in CI by `.github/workflows/content.yml`); `.github/workflows/android.yml` builds a debug APK on every push.
