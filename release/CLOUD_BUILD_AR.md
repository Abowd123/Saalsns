# بناء APK على سحابة GitHub

الملف `.github/workflows/android.yml` يبني نسخة **Android Debug** تلقائيًا بدون أدوات على جهازك.

## الخطوات
1. أنشئ مستودعًا **خاصًا** على GitHub وارفع المشروع إليه (يجب أن يكون `project.godot` في الجذر).
2. إذا لم يظهر المجلد `.github` بعد الرفع، أنشئ الملف يدويًا: Add file ← Create new file، الاسم `.github/workflows/android.yml`، والصق محتوى الملف.
3. تبويب **Actions** ← Build Madar APK. يبدأ تلقائيًا عند كل رفع، أو شغّله يدويًا بزر Run workflow. المدة 5 إلى 10 دقائق.
4. عند النجاح: **Releases** ← Madar debug (latest) ← حمّل `madar-debug.apk` وثبّته. وتجده أيضًا في Artifacts داخل صفحة التشغيل.

## ملاحظات
- يستخدم Godot 4.7.2. غيّر `GODOT_VERSION` في أعلى الملف إذا كان محررك إصدارًا آخر من 4.7.
- مفتاح التوقيع debug يُحفظ في الكاش ليبقى التوقيع ثابتًا بين النسخ. إذا تغيّر فاحذف النسخة القديمة من الجوال قبل التثبيت (وصدّر حفظك أولًا).
- إذا فشل البناء: انسخ آخر 30 سطرًا من سجل خطوة **Export APK**.
- نسخة Release الموقّعة بمفتاح الإصدار لا تُبنى هنا، وتحتاج مفتاح الإصدار كـ GitHub Secrets.
