# قائمة الفحص قبل الإصدار

نفس القائمة موجودة داخل التطبيق: أدوات المطور ← بوابة الإصدار. علّم كل بند بعد تجربته فعلًا.

## تلقائي (زر واحد)
- رقم النسخة، الكتالوج بلا أخطاء، 12 لعبة عامة.
- بنك الأسئلة صالح، وكل الأسئلة مراجعة يدويًا.
- الإنجازات والمتجر محمّلة.
- كل اختبارات الوحدات (أكثر من 100 فحص).
- اختبار دخان: تشغيل كل مرحلة من كل لعبة 0.6 ثانية مع التقاط أي خطأ برمجي.

## يدوي (22 بندًا)
| البند | كيف تجربه |
|---|---|
| التثبيت | ثبّت Release وافتحه |
| تثبيت جديد | الإعدادات ← التطبيقات ← مدار ← مسح البيانات، ثم افتح |
| الإغلاق القسري | اربح مرحلة، اسحب التطبيق من قائمة التطبيقات الأخيرة، افتحه |
| زر الرجوع | جرّبه في كل شاشة وأثناء اللعب |
| العربية | ابحث عن حروف منفصلة أو مربعات أو اتجاه خاطئ |
| اللاتيني | سؤال إنجليزي، سؤال CO₂، كلمة XP |
| كل الألعاب | المرحلة 1 من كل لعبة |
| شاشة النتيجة | زر التالي يظهر بسرعة |
| التحدي اليومي | أنجزه، تأكد أن الجائزة مرة واحدة |
| إرجاع الساعة | غيّر التاريخ يومًا للخلف |
| المتجر | اشترِ واستخدم |
| النسخ الاحتياطي | تصدير ← مسح البيانات ← استيراد |
| الصوت | الموسيقى والمؤثرات والأزرار |
| الصامت والاهتزاز | جرّب الوضع الصامت |
| الجودة المنخفضة | الخلفيات تتوقف |
| تقليل الحركة | لا اهتزاز ولا انزلاق |
| عمى الألوان | التعليمات المتغيرة بالأشكال |
| فحص الأداء | أرسل التقرير |
| البطارية والحرارة | 20 دقيقة لعب متواصل |
| وضع الطيران | كل شيء يعمل |
| الحواف والكاميرا | لا شيء مقطوع |
| التوقيع | Release موقعة بمفتاح الإصدار ومحفوظ في مكانين |

## عند وجود خطأ
أرسل: لقطة الشاشة + خطوات الوصول + ملف السجل (الإعدادات ← للمطور ← اختبارات الأنظمة ← نسخ التقرير يضم آخر 25 سطرًا من السجل).
